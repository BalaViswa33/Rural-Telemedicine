Installation
============

1. Navigate to directory:
   cd health-system-v2

2. Install dependencies:
   npm install

3. Start development server:
   npm run dev

4. Open browser:
   http://localhost:5173

5. Build for production:
   npm run build


Quick Test Scenarios
=====================

Test 1: Offline Patient Registration (ASHA)
1. Login as ASHA
2. DevTools → Network → Offline
3. Register patient
4. Record vitals
5. See "Offline Mode" indicator
6. Go online
7. Click "Sync Data"

Test 2: AI Prescription Parser (Doctor)
1. Login as Doctor
2. Select patient
3. Enter free-text prescription
4. Click "Parse with AI"
5. Edit if needed
6. Save

Test 3: Medicine Reminders (Patient)
1. Login as Patient
2. Go to Reminders tab
3. Enable notifications
4. See scheduled reminders
5. Click "Listen" for voice
6. Mark as taken

Storage Usage
=============

IndexedDB Stores:
- patients           → ~1KB per patient
- vitals             → ~500B per record
- prescriptions      → ~2KB per prescription

Estimated capacity:
- 1000 patients      → ~1MB
- 5000 vitals        → ~2.5MB
- 2000 prescriptions → ~4MB
Total: ~7.5MB (well within 50MB+ limit)
